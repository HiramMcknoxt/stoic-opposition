SURNIA — the plate reader the city owns

Open source · AGPLv3 · Free  Development build — not deployment-ready

SURNIA is an open-source license plate recognition system designed to be owned by the city that runs it. The cameras, the server, and the data belong to the public — not to a vendor renting them back by the month. Plate reads are matched against the state hot list on the city’s own hardware. Every search is written into a hash-chained audit log that cannot be quietly rewritten. A historical search requires a judicial instrument, a case number, and a second supervisor’s approval — no self-approval, and the attempts that get refused are logged too. Citizens can audit everything that is not criminal-justice data, down to keyed plate references.

The name is Surnia ulula, the northern hawk-owl: the owl that hunts in daylight, in the open. A watcher that is itself watched.

The code has converged through ten rounds of adversarial review. It has not yet had its independent penetration test or a production pilot, and no city should run it on live cameras today. The operator console below runs on sample data, so anyone can watch exactly how it behaves before believing a word of this.

Daedalus — drone footage, rebuilt as a place

Open source · Free

Daedalus is the craft of turning drone footage into explorable 3D places: fly a park, a street, a stretch of Arkansas sky with a camera drone, and the tools rebuild that place as a Gaussian splat — a cloud of points of light that holds the real light of the real place — so it can be flown again, walked, and built on. Everything is built from open parts, owned end to end. No rented black boxes.

This is Owlsight, the workshop’s viewer, opening the way it greets anyone: inside Richie Road Park in Cabot, Arkansas, rebuilt from a real drone flight as 528,204 points of light. Drag to look around; scroll to zoom; WASD or the arrow keys fly. File > Open in the viewer loads a splat of your own.

The scene is 17 MB and loads in pieces — give it a moment. For the web it is trimmed of 2,444 stray floaters — the giant, faint gaussians that smear a true renderer — the same cleanup the workshop’s own forge performs. A splat here is never shown against a black void: every surface renders it against a blue sky. That is a house rule, not an accident.

Live

Owlsight

The viewer that shows a splat the way it actually is — a true renderer in a single file that opens anywhere. No install, no server, no internet required.

Staging

Owlforge

The maker: drop in a flight video, get a finished splat out, from a window with buttons instead of a command line. Version 2 is built and staged; its first full shakedown runs are still ahead of it, and it is labeled accordingly.

otocoll

The tool that gives a splat walls: it builds the invisible collision geometry a game feels but never sees, tied by hash to the exact scene it belongs to.
